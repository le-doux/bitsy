| Término                         | Definición                                                   |
| ---------------------------- | ------------------------------------------------------------ |
| [Avatar](./tools/paint#avatar)  | El objeto que puedes controlar al jugar al juego.           |
| [Sprite](./tools/paint#sprite/) | Objetos con los que puedes 'hablar' al jugar al juego.         |
| [Tesela](./tools/paint#tile/)     | Objetos decorativos, no puedes interactuar con ellos.     |
| [Objeto](./tools/paint#item/)     | Objetos que puedes 'recoger' y guardar en el inventario.  |
| Dibujo                      | Un término general para describir avatares, sprites, teselas u objetos. |

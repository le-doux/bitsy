# Sobre Bitsy

> ¡hola! bitsy es un pequeño editor para juegos o mundos pequeños. su objetivo es hacer fácil crear juegos donde puedas caminar, hablar con personas y habitar espacios.
>
> ¡diviértete creando con bitsy!
>
> &ndash; <cite>[adam](https://www.twitter.com/adamledoux)</cite>

## Primeros pasos

¡Aquí hay algunas buenas páginas para empezar a aprender sobre Bitsy! :)

- Empieza con una [visión general](/docs/introduction/overview) del editor de Bitsy
- Lee un [tutorial](/docs/introduction/tutorial) hecho por un miembro de la comunidad de Bitsy
- ¡O écha un vistazo a las [preguntas frecuentes](/docs/category/FAQ) para encontrar una respuesta a las preguntas más comunes!
